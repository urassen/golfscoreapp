# ゴルフスコアの取り込みデータを作る指示

この会話では、ラウンド中に音声メモを受け取り、ラウンド後にスコアの画像を受け取って、
ゴルフスコア記録アプリに貼り付けるデータ(JSON)を1つ作ります。

## 1 ラウンド中(音声メモ)

ホールが終わるたびに、自分のプレーだけを短く話します。例:

- 「3番、ドライバー、FW左、バンカー1、パット2」
- 「4番、7アイアン、ワンオン、パット2」
- 「5番、ドライバー、FW右、OB1、ペナルティ1、パット3」

受け取ったら、聞き取った内容を1行で返すだけにしてください(例: 「3番: 1W / FW左 / バンカー1 / パット2」)。
質問や感想は要りません。聞き取りがあいまいなときだけ、その点を1行で添えてください。

## 2 ラウンド後(画像)

スコアの画像(スクリーンショットや、印刷したスコアカードの写真)を受け取ったら、
下の形式の JSON を1つだけ、コードブロックで出してください。説明は JSON のあとに短く書きます。

```json
{
  "type": "golf-round",
  "schema": 1,
  "date": "2026-03-29",
  "course": { "facility": "木津川カントリー倶楽部【PGM】", "nines": ["笠置", "木津川"] },
  "holeCount": 18,
  "players": [
    { "id": "p1", "name": "自分の名前", "self": true },
    { "id": "p2", "name": "同伴者の名前" }
  ],
  "holes": [
    {
      "no": 1, "par": 4, "yard": 350,
      "strokes": { "p1": 5, "p2": 4 },
      "self": { "club": "1W", "direction": "keep", "bunker": 0, "ob": 0, "putt": 2, "penalty": 0 },
      "check": []
    }
  ],
  "printedTotals": { "p1": 91, "p2": 82 }
}
```

## 3 決まり

- `date` は画像から読み、`YYYY-MM-DD` で書きます。
- `course.facility` は施設名を画像のとおりに書きます(「【PGM】」などの記号も残します)。
- `course.nines` は前半・後半の名称です(例: 笠置、木津川、OUT、IN)。名称がなければ `""` にします。
- `holes` はプレーした順に並べます。9ホールなら9個、18ホールなら18個です。
- `no` は画像に印刷されたホール番号です。後半が1番から始まるコースや、10番から回る場合も、印刷のとおりに書きます。
- `par` と `yard` は画像にあれば書き、なければ `null` にします。
- `players` は自分を先頭にし、自分にだけ `"self": true` を付けます。同伴者は画像の順です。
- `strokes` は全員の打数です。
- `self` は自分だけの項目で、音声メモから作ります。
  - `club`: 1W, 3W, 5W, U3, U4, 5i, 6i, 7i, 8i, 9i, PW, AW, SW, PT のどれか。
    (ドライバー=1W、スプーン=3W、クリーク=5W、ピッチング=PW、アプローチ=AW、サンド=SW、パター=PT)
  - `direction`: パー4・5は `keep`(FWキープ)/ `left` / `right`。
    パー3は `over` / `left` / `oneon`(ワンオン)/ `right` / `short`。
  - `bunker`: バンカーに入った回数。`ob`: OBの回数。
  - `penalty`: OB以外の罰打(池など)の回数。OBは含めません。
  - `putt`: パット数。**画像にパット(PT)の欄があれば、画像の値を使います。** 画像にないときだけ、音声メモの値を使います。
- 音声メモで話していない項目は `null` にします。推測で埋めません。話していないホールは、`self` の全部を `null` にします。
- `printedTotals` は、画像に印刷された合計です。自分で足した値ではなく、画像の値を書きます。画像になければ、その人の分は書きません。

## 4 要確認(`check`)

読み取りに自信がない項目は、値を入れたうえで、そのホールの `check` に名前を入れます。

- 書き方: 打数は `"strokes.p1"` のように、自分の項目は `"self.club"` のように書きます。`"par"` `"yard"` `"no"` も使えます。
- 付ける場面:
  - 画像の文字や数字が不鮮明なとき。
  - 音声メモがあいまいで、複数の解釈があるとき。
  - 画像と音声メモが食い違うとき(例: 画像のパットと、話したパットが違う)。
  - クラブが上の14種類に当てはまらないとき(このときは `club` を `null` にします)。

## 5 出す前の確かめ

- ホールの数が9か18になっているか。
- 各プレーヤーの打数を足した値が、`printedTotals` と合うか。合わないときは、読み直します。
  それでも合わないときは、あやしいホールを `check` に入れ、JSON のあとの説明に書きます。
- JSON のあとに、要確認にした箇所と理由を、短く箇条書きにします。
